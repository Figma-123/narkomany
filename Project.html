Task Manager

Разработчик: Иван Петров

Веб-приложение для управления задачами и проектами. Позволяет создавать списки дел, назначать сроки, отслеживать прогресс и работать в команде.

Основные возможности: создание и редактирование задач, дедлайны, фильтры по статусу, совместная работа.

Weather Bot

Разработчик: Анна Смирнова

Телеграм-бот, который показывает текущую погоду и прогноз на несколько дней по названию города. Данные берутся из открытого API.

Основные возможности: запрос погоды по городу, прогноз на 5 дней, уведомления об осадках.
